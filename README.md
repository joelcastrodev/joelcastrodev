## Cómo trabajo

- **Documento el proceso, no solo el resultado.** Si no se puede repetir, no está terminado.
- **Datos ficticios desde el primer commit.** Nunca "anonimizo después".
- **Pruebas antes que confianza.** Cypress para los flujos críticos.
- **Diagramas versionados.** Un `.mermaid` vale más que una captura de pantalla.
